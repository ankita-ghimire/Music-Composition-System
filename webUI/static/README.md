# 🎵 Soundfonts Setup

This folder should contain instrument soundfonts (SF2/SF3 files) used by the Music Composition System.

## Required Instruments
- Salamander Piano
- Flute
- Violin
- Acoustic Guitar

## Setup Instructions
1. Download the soundfonts package from this link:  
   👉 [https://drive.google.com/drive/folders/15fETNNZsPfubCv804k121PHeT3u7v4Ce?usp=drive_link]

2. Extract the folder and place the instrument subfolders here:  
webUI/static/soundfonts/

The structure should look like this:


webUI/static/soundfonts/salamander-piano/
webUI/static/soundfonts/flute/
webUI/static/soundfonts/violin/
webUI/static/soundfonts/acoustic-guitar/


1. Restart the server and the instruments will load correctly.
